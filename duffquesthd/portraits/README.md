# Dialogue portraits

Hazbin-style cartoon sheets for the dialogue box. Each file is a 1280×720 PNG: three head-and-shoulders expressions in one row, facing right. The flat `#00FF00` green is a chroma key. Key it out when a portrait sits in the dialogue box.

Left to right on every sheet: **happy**, **deadpan**, **furious**.

These are the original files. Nothing in the game references them yet.
